# MyOrders

A clean and modern Android UI for Myorders Page, built using Kotlin and XML.

## Features

- Order listing using RecyclerView
- Interactive order tabs
- Ripple click effects
- Floating help button
- Bottom navigation
- Smooth UI interactions
- Responsive layout

## Built With

- Kotlin
- XML
- RecyclerView
- Material Components
